# BEV 鸟瞰作为引导线坐标系

## 最终结论

图 12 不规则，是因为 IPM 只摊了「此刻看得见的地」；车和人把路挡住，鸟瞰就被咬出缺口。黑底已经是矩形米制网格，缺口是遮挡真相，不是画布坏了。

和原图 1:1 的正确落点是**把线投回摄像头叠在实景上**（图 18），不是把鸟瞰当成第二张照片。

结构化路面 = 后融合双层：层 A 可见自由空间（主线，遇障停）；层 B CPU 补全被包围/咬掉的马路（虚线，穿障标风险）。补全不是「可以开」。3DGS / BEVFormer 本轮不采用。

## 引导线产品口径（乔布斯锁定 · 2026-09-20）

引导线（蓝）必须被车道线约束。车道线不准，引导线没有使用资格。

车道线不等于路面上已画的涂料。看不见的也要由模型/算法认出来、补出来（虚线缺口、近处漏画、牙子当右边）。认出来的是**几何轨**。黄线画司机能看见的车道线：CamVid Lane 涂料折线（含邻道实线）+ 占用车道若缺涂料则用牙子。蓝线仍只夹在**占用车道**那一对中间。

蓝线夹在占用左右轨中间，顺着弯走，遇障停。禁止：两根涂料取中却缺轨就漂；把灯柱/岛沿碎点当轨；用平滑掩盖错误边界；只画占用一对却把旁边明明存在的白实线藏掉。

验收：先看黄轨是否就是司机看见的那两条边；再看蓝线是否夹在里面且不 S。数字（Δψ）不能替代这张图。
