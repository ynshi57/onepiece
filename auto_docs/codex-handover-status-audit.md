## 3. 功能实现到哪一步

### 户外四项核心（产品宪法第一优先级）—— 自 10-04 起基本停滞

- 车道线：live 用 TwinLite 折线；UFLDv2 decoder 在代码里但 live runner 可能为 nil，**未上线**。
- 可通行区按人/车区分：mc5 已打包但默认关，live TwinLite 不分人车，**核心第 2 条未兑现**。
- 障碍：YOLO11n；台阶/路沿**无实现路径**（只有“以后靠边界/深度”）。
- 实时性：本地感知约 5Hz 节流；**缺端上 p50/p95 延迟验收数据**。
- 室内场景会喷假车道/假可走区，OOD 门闩仍在“以后再做”。

### 室内空间扫描（10-10 用户转向，当前主要投入）—— 采集/保存/运输通，A/B/C 均未达标

- 已通：iPhone RGB+IMU ARKit 采集、平面/轨迹/关键帧、本机保存、ARWorldMap 跨次恢复、完整 ZIP 导出（256MiB）、Mac 导入与浏览器回放。1015 真机 179 照片样本手机原 ZIP → Mac 全 SHA 一致、页面可见。
- A（定位/漂移/重入）：只有 ARKit 内部一致性（如恢复 7.4 秒、平面差约 8cm），**无独立真值精度**；20 米漂移、快速运动、白墙玻璃失败率、真机性能门未测。
- B（墙/地/门结构语义）：SIFT/SP+LightGlue 稀疏点、SegFormer/GroundingDINO 研究；画架仍被误标为墙，完整墙体/房间拓扑/尺寸**未实现**。
- C（3DGS 外观）：Brush 官方训练可跑，最佳约 25dB，但 13 张开发图**全部仍重影**；512 分辨率实验退步；10 万高斯容量实验文档写“继续中”，无结果记录。
- 旧“物品记忆”：自动判断移走/遮挡、三维轮廓未实现，已降为菜单入口。
