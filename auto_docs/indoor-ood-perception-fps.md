# 咖啡店实测 · 室内 OOD + 感知帧率

## 用户现象

咖啡店室内：画面像不动；车道线与红色可走区持续乱变；觉得不实时。

## 乔布斯结论

1. TwinLite **不适用于室内** — 户外街景才是承诺范围（已写 CURRENT）。
2. 「假线乱跳」是域外幻觉，不是用户操作问题。
3. 实时性：预览是视频；感知曾被 2.0s 节流绑死 — 已拆本地 0.2s / 远程 2.0s，感知异步。

## 帧率答案

- 传给本地感知：**离散帧，目标 ~5 Hz**（`minLocalPerceptionInterval=0.2`），忙则丢帧。
- **不是**连续视频流进模型。
- 相机预览层仍是连续视频。

## 已执行

- `StreamingLimits` 拆分；`FrameCaptureProxy` / AR 异步感知；本地跳过 JPEG
- CURRENT + 技术雷达卡 + 空闲提示文案
