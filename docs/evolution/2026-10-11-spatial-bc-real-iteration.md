# B/C 真实采集迭代：校准、初始化与失败实验

## 产品裁决与分工

乔布斯：A 恢复环节一次真机成功不意味着 ABC 完成。本轮使用已保存的 239 张真实室内照片推进结构与外观，不要求用户逐张解释或重扫。验收必须看原照片与渲染，未知区域和失败不能从指标删除。

小马独立只读审查：有条件同意，先修 PIL resize 的像素中心内参，再用固定 holdout 对照视图选择，区分 AR 位姿一致性和图像匹配误差。全麦独立执行训练：有条件同意，增加初始化基线、全图 PSNR、alpha 覆盖；单纯更多高斯可能更慢且更糊。罗根/思余由主代理按角色自审：同意可追溯实验，训练中断与旧结果必须可见；页面应标明定位段、原照片编号、训练前后列。后两项不是独立员工审查。

任务/接口：小马负责只读相机与视图研究；全麦负责 CPU 训练器及测试；主代理负责共享内参、dense、API、页面、真实浏览器及文档。模型结果提供列定义与原照片编号；API 校验来源并公开中断状态；页面消费实际产物。依赖与安装 profile 未新增，正式 Brush 尚未安装。

## 改动与影响面

- `spatial_reconstruction.resize_intrinsics` 单真源：像素中心满足 p'=(p+.5)s-.5，原 K 不修改。同步 dense 参考/目标投影、CPU 高斯训练、Nerfstudio 导出；dense 支持点的原图像素坐标同步反变换。
- dense 增加姿态限定 overlap/lateral-baseline 选择实验；holdout 固定，与原时间邻居法一致。不读取 holdout RGB 来选择训练视图，失败方案不默认启用。无法处理的选中视图计入未知像素分母。
- 高斯训练增加训练种子最近邻尺度、独立初始化快照、优化结束后读取验证 RGB、全图指标/alpha 图、分阶段耗时。密度分裂只读训练梯度、容量 1000，默认关闭。
- API 原子写状态，启动失败释放锁，服务重启导致的孤儿训练明确失败。document/manifest 来源改变或旧任务无来源校验时拒绝展示为当前模型，保留旧产物。标准 PLY 字段未变。
- 页面重新打开自动读取已有任务；展示定位段与原照片编号，按产物列元数据显示原照片/训练前/训练后。旧两列产物兼容。

## 真实证据（不能据此称完成）

全部 239 张的 sparse：3601 点，818 次 holdout 中 193 通过、625 失败，p95 26.996px。133 对有独立 F 支持且基线足够的照片，AR 预测极线误差中位约 2.69px，图像自身拟合约 0.58px；后者是同观测拟合，不是独立验证，也不证明 AR 是唯一根因。

固定 12 个 dense 参考视图/147456 像素：修正内参后支持 1260，未知 146196，holdout 失败 2043；旧内参支持 1281。校准错误修复不等于质量提高。姿态重叠选择仅支持 162、未知 147294，失败 380，耗时 8.90 秒，效果恶化，默认继续时间邻居法。未知白墙没有补画。

真实定位段 3，固定 13 张 holdout，64px/240steps/600 初始点：

| 实验 | 训练后 PSNR | alpha>=.5 覆盖 | 总耗时 | 优化耗时 |
|---|---:|---:|---:|---:|
| 固定尺度 | 12.733 dB | 82.2% | 67.01s | 36.61s |
| 最近邻尺度 | 14.597 dB | 87.8% | 66.69s | 37.43s |
| 训练梯度分裂 600→864 | 13.421 dB | 70.7% | 73.88s | 45.27s |

最近邻初始化基线 13.014dB；密度分裂使用相同初始快照，验证未参与选点。分裂质量下降而耗时增加，默认关闭。主代理和训练执行者均看真实验证图，桌沿、书本、椅子细节仍丢失，不能验收 C。

实际浏览器对 239 张记录点表面重建→高斯训练→选择验证照片，零页面脚本错误。默认选择照片最多的定位段 2，600 点、22 张 holdout、91.23 秒，平均 PSNR 13.7dB；页面明确段号，不与另一定位段拼接。重新打开同记录自动显示结果，239 张照片及三列渲染正常加载。该结果仍是低质量参考实验。

## 已训练模型的自由视角诊断

新增 `spatial_splat_viewer.js`，直接读取当前训练任务的 `splats.json`，由三维尺度、单位化四元数计算协方差，透视 Jacobian 投影为椭圆高斯，深度排序后透明混合。Canvas 渐变是近似预览，不是训练器逐像素 GPU 渲染，不能据预览图验收画质。固定世界 Y 向上、拖动旋转、滚轮缩放、回正；明确独立定位段，不拼接另一段轨迹。

API 同步开放受来源校验保护的 `splats.json` 和本地 JS 静态文件；HTML 同步新增旋转查看入口，原训练模型保留。新增 4 项 JavaScript 数学/模型校验测试；实际浏览器加载定位段 2 的 600 个高斯，拖动与缩放改变画面，回正恢复完全相同 Canvas 图，无脚本错误。主代理也看图：仍是模糊团和空洞，家具和完整房间无法辨认。自由视角操作通过，C 画质验收仍失败。
