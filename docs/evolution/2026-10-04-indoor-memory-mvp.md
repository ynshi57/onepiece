# 室内物品记忆 MVP

## 用户目标

在家、书店或咖啡店中，用户用手机扫过桌面，手动命名一个物品；随后移动手机，看到同一次使用中记录的空间位置。

## 产品裁决

- 入口独立于户外看路页面，避免室内误画车道或可走区。
- 只接受 ARKit 已检测的水平真实平面，不用 estimated plane 或固定距离补点。
- 记录时冻结同一 ARFrame 的照片、平面命中点和时间。
- “上次记录位置”不等于“物品现在仍在那里”；跟踪中断、后台恢复、重新扫描后旧坐标失效。
- 照片只在本次应用内存中保存，不上传、不写入相册。

## 已实现

- 室内 ARKit 页面、水平平面扫描、准星、命名保存、最近记录、历史照片、删除和诊断摘要。
- 室内/户外相机互斥；户外控制器退出前会停止捕获、发现、定位和语音迟到回调。
- 物品记录绑定会话 UUID、跟踪状态和帧龄；屏外或镜头后方只提示转动手机。

## 验证边界

- 历史版本已验证：首次编译通过及 129 项 XCTest/UI 测试；后续独立运行通过 8 项 IndoorMemoryTests + 2 项 IndoorMemoryUITests，最后安全区/按钮对比度修复后通过 2 项 UI 测试。这些运行不能相加，也不能证明之后的语音状态与第二次 raycast 距离修复已完整验证。
