# 空间理解与持久记忆：产品与实现设计

2026-10-17用户裁决：最终运行于iPhone，照片在设备本地处理与保存；Mac用于开发/离线实验。云模型不是前置依赖。首个端侧增量为停止扫描后识别已有关键帧，保存未经核实的二维检测、失败与历史；不得将相机位置当物体位置。实时感知、可靠3D及跨次身份仍独立验收。

修订：2026-10-26，矢量化产品形态定为记忆视图（已观测墙、家具缺口、未看见的边）；封闭户型图不是本阶段交付，转圈完成不等于房间完成。2026-10-25，第8节细化M2证据与独立验收；2026-10-16直接修订原《物品记忆：采集、回放与核心算法详细设计》。本轮用户明确的目标优先于此前“墙线/高斯外观”的局部目标。下文区分目标、已有事实和待验证能力。

## 1. 目标、核心思想与意图

让 VQASee 知道用户所在物理空间长什么样、里面有什么，记住它们的位置，并在再次观察时辨认、核对和更新。用户得到的是有依据的空间记忆，不是一次图片描述。

用户任务：查看这个房间的布局和物品；问“画架在哪”“门旁边有什么”；离开重返后找回已有记忆；物品移动时更新位置，被遮挡时保留历史而不误判消失。

核心表示是带证据和时间的场景记忆：空间结构＋具体物体＋位置/关系＋观察历史。矢量图是它的一种视图，照片是观察证据，ARKit 是定位底座。照片渲染得像、墙线变多、文件保存成功，均不能独自证明目标成立。记忆视图过门：墙与家具分开、没看见的边保持开口并写「还没看全」、同一证据能点回原图；不把中间转圈的封闭户型当作验收。

学习模型承担类别/实例轮廓、外观特征和结构预测；多视角几何/深度约束位置；记忆层负责关联、保存和更新。几何规则只作一致性校验，不继续用“高于1.2米即墙”等启发式代替语义识别。RL 暂不作为首任务：先建立可测误差、样本与反馈，再判断是否适合主动观察或关联策略优化。

## 2. 当前真实起点

2026-10-17增量：已接入端侧检测归档；本地学习型双向光流与同epoch三角化进入区域表面证据实验，含稳定来源、失败历史及照片点叠加，尚待真机网络自校准和实景准确度/耗时验收，未成为物体位置或身份。见 `2026-10-17-object-surface-evidence.md`。

- `SpatialScanDocument` 已有 RGB 关键帧、同帧内参/位姿、epoch、原始平面与地图恢复记录；没有场景对象库存。
- `IndoorMemoryRecord/Store` 已有用户命名的少量目标、照片/轮廓、AR锚点和最近一次人工确认。它不是自动全场景理解，锚点UUID不能直接充当跨次物体身份。
- 当前矢量墙线来自原始面归组与投影；RGB 墙根核对受既有墙方向约束。完整墙体、门窗、物体轮廓尚未恢复。
- 神经网络基线优先复用现有可运行的 CPU SegFormer。它输出语义区域，不提供具体物体身份或可靠三维位置；ZeroPlane/SceneScript 为候选，不是已采用方案。来源与约束见 `docs/tech-radar/2026-10-16-learned-vector-mapping.md`。
- 旧采集/回放继续复用：同帧图像与相机信息、本地存储、失败可见、删除和隐私策略。无需重新发明录制系统。

## 3. 数据和模块接口

```text
RGB + 相机/跟踪/内参（ARKit；可选真实深度）
 → 学习型观测：类别区域、实例候选、外观、结构候选
 → 空间定位：多视角/深度 + 有效坐标变换 + 位置误差
 → 关联与记忆：新增、再次看到、候选匹配、位置更新、冲突
 → 查询和视图：空间总览、原图证据、找物、变化核对
```

- Space：独立spaceID、名称、坐标参考/版本与恢复状态；scanID/session/epoch是观测上下文，不等同spaceID。
- Observation：不可变observationID，scanID/frameID/epoch/原始帧时间、可用绝对时间、模型来源、语义区域/轮廓、模型分数、可见性与失败。没有绝对时间不编造“今天看到”。
- Entity：独立entityID，类别与可选用户名称，多视角外观引用；关联到多个Observation。语义类别“椅子”不等于“同一把椅子”，无法区分时保留竞争候选。
- Location：属于哪个space/坐标版本、3D位置及范围、朝向/大小、来源和误差。仅二维区域时worldPosition必须未知；射线命中背景不得冒充物体中心。
- Relation：靠近/位于门旁等关系必须引用有空间支持的实体；没有可靠位置不得由文字模型补写。
- History：追加观察/位置变更/关联纠正；维护当前最佳状态，但不覆盖旧证据。未看到、遮挡、出画、定位失效均不等于移走或删除。

首实现采用独立语义观察sidecar，引用既有扫描和关键帧，不改变旧扫描协议、不强行迁移旧物品UUID。sidecar查询返回候选与证据；将来实体/空间关联通过显式版本接口接入，禁止把临时regionID提升为永久身份。

## 4. 观察、记忆和回答规则

观测状态：当前看见 / 历史记录 / 位置待核对 / 遮挡或视野外 / 身份存在歧义 / 处理失败。

再次进入先验证坐标恢复，再做外观与空间联合关联；恢复成功不自动确认物体仍在。移动更新需要同物身份和新位置证据；无此证据只能保存候选。原处未见只能说明这次观察未找到，不能推出从房间消失。

问答从结构化记忆检索，回答携带空间、最后观察时间与证据；“在哪里”无可靠3D时明确不知道位置。自然语言模型可组织措辞，不负责捏造库存和坐标。视图明确区分当前、历史和待核对，支持用户纠错但不把手动纠错包装成自动能力。

## 5. 重审与最终裁决

乔布斯先定方向：从扫描/外观重建转回空间理解与持久记忆。首交付必须让真实神经网络观察进入可查询记录，避免又只做日志和文案。

独立复审：罗根有条件同意，要求session/坐标版本/恢复状态分离，遮挡不能删除，关联失败可恢复；思余有条件同意，当前/历史/待核对必须分开并能查看证据；全麦和小马有条件同意，语义连通区域会合并/拆分物体，不可算实例，离线CPU耗时不等于端上实时。

乔布斯最终采纳：先闭环真实学习型观察→保存→重载→查询→原图看图，后续按位置、身份、跨次更新分别验收。已有原始数据和失败全部保留。不将CUDA模型移植、高斯、无限技术选型纳入首轮。

## 6. 任务卡、顺序和联调

1. **M1 学习型观察进入记忆（本轮执行）**。全麦主责模型推理，罗根配合持久化；范围为本地研究runner、语义sidecar与测试。固定六张真实照片覆盖扫描时间，全226帧分母保留。交付原图/叠图、逐帧状态/耗时、全部语义候选、保存重载查询。验收是证据完整与可用，不是识别准确度通过。尚未处理的220帧保持未处理，不能算成功。
2. **M2 物体位置**。按第8节先验证少量静态实体的可见表面点：原始像素/坐标链校准、双侧实例归属、可观测性与误差传播，再用留出视角和独立物理测量验收。罗根/全麦主责，思余呈现同一证据。框内三点及框估宽高只作未验证候选，不作为物体中心或完整尺寸；无真值不宣称米制精度。
3. **M3 同物关联与跨次更新**。全麦主责，罗根保存追加历史；同类相似物竞争、移动/遮挡/替换/重入分开评测。验收两次进入同一房间：更新移动物体、保留遮挡物体历史、拒绝相似物误认；错误和拒绝均计数，不靠全“不确定”过关。
4. **M4 面向用户的空间记忆**。思余主责，乔布斯验收；默认扫描入口与旧物品入口共享同一证据/实体接口，呈现空间总览、找物和核对变化。联调需真实手机屏幕和历史查询，API/文件成功不等于用户可用。

每阶段由上一阶段的带来源结果作为接口输入；罗根返回失败与耗时，全麦返回分割/身份/位置误差，思余返回真实屏幕，乔布斯看图裁决。单一具体假设第二次失败就停止，不扩成另一个工具链项目。

## 7. 验收、隐私和边界

- 分别测语义/轮廓、实例关联误认漏认、位置误差、重入成功率、更新错误、自动结论覆盖及端到端p50/p95；按真实场景/会话拆分，不能相邻帧拆成独立测试。
- 六帧探索不验证泛化。保留请求总量、未处理、模型失败、无法定位与身份歧义。人工标注是独立真值，不是算法输出。
- 不以PSNR、高斯数量、墙线数量作为核心验收。空间结构和对象必须回到原图、俯视位置与真实摆放核对。
- 图片和记忆默认本地，用户可删除；远程推理/上传需明确数据范围和用户授权。新模型/依赖进入产品时同次同步安装清单与setup；离线研究候选不改生产默认值。
- 目前未完成可靠3D、实例身份、跨次更新和App统一入口，不能称“空间记忆已实现”。真实尺寸、移动/遮挡/相似物与重入样本仍需现场证据。

首轮执行状态见 `docs/evolution/2026-10-16-scene-memory-redesign.md`；M1真实推理、保存重载查询与看图链路已跑通，语义准确度未通过；M2位置候选及后续阶段尚未验收。


## 8. 2026-10-25 修订：先证明一个物体的可见表面位置

本节是用户要求的方案修订，不是实施记录或能力验收。本节细化 M2，不扩大到全屋重建、全局 BA、模型训练或 M3 身份。当前代码只有候选能力；`SPATIAL_HANDOFF.md` 仍是执行状态入口。下面的算法组合与指标是本项目的设计选择，不冒充所有专家共识或论文实测结果。

### 8.1 专家会额外做的工作

1. **先定义被测量是什么。** 二维框不是物体表面，框中心不是物体中心，框内三点也不证明物体归属。M2 首个输出改为“已核对属于该实例的可见表面点及不确定范围”；稀疏点均值只能叫支持点代表位置。未观测到的背面、厚度、完整物体宽高和中心保持未知。三个点近共线时不能稳定估计表面朝向。
2. **先校准，再求位置。** 核对原图尺寸、旋转/裁切/缩放矩阵、内参所对应像素域、世界到相机与相机到世界方向、单位、同帧时间、epoch、跟踪状态。使用未参与拟合的标定图/控制点检查投影。不能对已校正图重复去畸变，也不能假设导出的 JPEG 仍与 ARFrame 内参完全对应。
3. **判断是否可观测。** 纯旋转或小视差无法可靠测距；按实际三角化夹角、点轨迹和数值条件选配对，不只选时间最近或相机位移够大的帧。检查正深度、遮挡、对应循环、极线与重投影残差；这些是内在一致性，不是独立真值。
4. **把错误关联与噪声分开。** 当前物体区域只检查 source 框；修订要求 source/target 两侧实例区域与可见性一致，边界/背景竞争明确拒绝。先用少量人工实例掩码建立几何上限，再对照自动区域，不先引入新模型。对应点通过 RANSAC/稳健损失剔除离群，保留原始匹配和拒绝原因；相关点不能按独立样本累加置信度。
5. **量不确定性，而非计点数。** 固定已核对位姿，使用多视角加权三角化及点位置非线性重投影优化。把像素误差和位姿扰动传播到位置，检查雅可比秩/条件数；位姿协方差缺失时报告假设敏感性区间，不能冒称校准的95%置信区间。只有残差证明位姿问题时才提出局部位姿优化，不自动做全屋 BA。
6. **做留出与消融。** 用未参与估计的照片测预测；分别对比原两视角、人工掩码、自动区域及含不确定性的版本。加入低视差、框内背景、遮挡、重复纹理和错误epoch负例。既计准确率也计覆盖率、拒绝率，避免全拒绝或只展示最好一帧。

### 8.2 从最原始的素材出发

建立最小输入清单，先标记“已存在/未采集/不可获取”，不把讨论帖、PNG、JSON汇总或已有模型标签当真值：

- **原始传感观测：** 未叠图RGB关键帧或原始视频、原始帧时间、同帧内参/相机位姿/跟踪状态/epoch；实际保存了多少就承认多少。若没有原视频、原始IMU、畸变参数或位姿协方差，明确缺失，不从压缩图或ARKit结果伪造补齐。
- **像素处理履历：** ARFrame到归档图、再到模型输入的尺寸、旋转、裁切、缩放与坐标变换；检测框、分割mask和逐点对应都回溯到同一个原始像素域。
- **逐帧原始算法产物：** 未汇总检测框/mask/分数、候选匹配坐标、循环/重投影误差、失败和被拒绝样本；单独标明这些仍是预测。语义记录frameID只证明来源，不证明该帧实际看见全部墙段或物体。
- **独立物理资料：** 同场景可辨认的物体表面特征点、尺量/激光测距值、控制点与测量重复性记录；用独立控制点定义参考坐标，再测目标点。拟合坐标的点与最终评分点分开，不能用待测物体反过来修正尺度。
- **原始负例：** 拍不到背面、移出视野、被遮挡、同类相似物、纯转动和运动模糊等片段，不能只取成功观测。优先检查已有原件；缺失才补采，照片不上传云端。

真实深度仅在设备支持且实际采集时使用，带深度confidence/时间/坐标映射；深度网络预测不能贴上“传感器真值”标签。RoomPlan需要LiDAR设备，不能假设当前手机具备；独立测量不要求用户先购买新设备。

### 8.3 具体算法与工具，只保留一条主线

- **主线：** 既有端侧检测/对应 → 双侧实例归属与遮挡核对 → 按视差和条件数选择少量视图 → OpenCV `triangulatePoints`/SVD初值 → 加权稳健重投影优化 → 位姿/像素扰动敏感性 → 原图与俯视显示同一支持点集合。`undistortPoints`只在像素链证实有对应畸变模型且尚未校正时使用；ChArUco/棋盘仅用于控制校准。
- **离线核对：** OpenCV作已知输入的独立数值实现；COLMAP已知相机位姿的稀疏三角化作对照，明确它与App共享位姿时不独立验证尺度/漂移。Ceres只在小规模稳健优化/协方差参考确有需要时采用，不将其引入iOS依赖。不同实现不等于独立物理证据。
- **外部对照：** ETH3D等带独立扫描真值的数据只验证通用几何组件；同房间RoomPlan只在已有LiDAR设备可用时作对照，不能替代量具或证明同款手机产品可用。均不在本轮下载/运行。
- **产品与性能：** XCTest验证协议、保存/重载/导出及旧快照失效；XCUITest验证用户入口和失败恢复；`os_signpost`与Instruments分别计模型冷启动、匹配、几何、存储和首屏。Mac运行耗时不当成iPhone性能。

本次只是修改方案，无新增依赖或安装动作；真正引入工具时必须同次同步setup_mac/requirements/README。现有XCTest用同一个`SpatialStructureSnapshotCache`构造expected，再与实际存档比较，只能证明派生规则一致；须另用独立原始真值验证几何，不能让被测实现自己当裁判。

### 8.4 除了我们，什么能证伪结果

1. **物理真值：** 不参与调参的人用可检查的尺量/激光测量表面控制点及若干独立边长，记录工具误差与重复测量；评价同一个物理量，不拿表面点与物体中心比较。只做刚体坐标对齐，米制评分禁止重新缩放；不规则物体若量具不能确定点位，则该位置真值仍缺失。RoomPlan/另一个网络只能辅助对照。
2. **留出证据：** 在冻结的未参与估计照片上由盲标人员标注可见点/实例区域，核对重投影与点归属；留出照片、测量表与阈值不得再用于拟合。本检查验证预测泛化，不能独自证明绝对尺度。
3. **独立实现/可复现：** 给另一位工程师固定输入、接口、环境和评价脚本，重算结果；先用解析几何测试坐标/单位/符号，再用公开真值数据及同场景量具验证。系统性共用误差须单列。
4. **负例与用户旅程：** 所有计划对象/帧为分母，公布错误发布、拒绝和失败，不能以点多/线多/测试绿代替位置正确。真实入口走扫描→停止处理→查看位置和原图→保存→重启→回读，误差及失败状态必须保持一致。

这些构成受限条件下的可反驳证据，不是数学上证明所有房间永远正确。当前真实位置精度、首屏时延、身份与跨次更新仍未通过。

### 8.5 修改后的最小实验与执行闸门

- **范围冻结：** 1个房间、3个静态实体（有纹理、弱纹理、易混背景各1），距离1–3m。12张有横向视差的关键帧，事前固定8张估计、4张留出；另保留少量低视差/遮挡负例。不同对象可见性不够时记缺失，不能用同一静态帧复制充数。此样本只作试点，不足以估计总体p95或宣称普适性能。
- **先行校准：** 查素材及像素链；用人工掩码/已知对应验证几何上限。若人工上限也失败，先修标定/位姿/几何，不跑更大模型。上限成立再用同输入检验自动区域，对比错误归属和覆盖损失。
- **预注册工程目标（尚未达到）：** 同一可辨认表面点的3D误差≤10cm（1–3m），参考测量不确定性≤2cm；3个正例均有可评价候选，指定背景/低视差负例不错误发布已确认位置。物体完整中心、宽高、厚度不参与此门，也不允许从框推断冒充已通过。留出像素误差与不确定性覆盖另外报告，门槛由校准误差模型事前冻结，不能看结果再放宽。样本不足时报告每项误差与失败，不计算虚假的p95。
- **耗时预算与停止：** 运行前说明12帧、实际配对数、设备和缓存状态；校准、推理、几何、构建、传输分别计时。首个iPhone冷启动及单配对耗时未知，必须先量；首个配对60秒未完成即停止批处理并暴露超时，不据此删除该样本。60秒是试验资源上限，不是产品延迟承诺。仅在首对成功且已报实际耗时后推进固定小样本；每30秒报告实际阶段。同一具体假设第二次失败停止。
- **完成门：** 量具误差+留出投影+物体归属+覆盖率同时合格，且从真实用户入口保存重启可见，才允许称“该试点表面位置已验证”。首屏/处理耗时必须实测，后续产品时延目标据使用场景预注册，不以本轮试点冒充实时可用。缺物理真值则只交几何一致性，不交米制准确性结论。

### 8.6 五角色审查、任务卡与联调

以下是本次按角色视角的设计自审，并非已召集独立专家或执行新实验：

- **乔布斯初裁：** 加深M2位置证据，不加功能页或全屋算法；原“框内三点+框估宽高”不能作为可靠物体位置验收。
- **罗根：有条件同意。** 困难是像素/坐标版本和位姿误差缺失；替代方案先固定已核对位姿，只估计点。主责素材链/版本/耗时，配合全麦；范围采集metadata与既有Store接口；交付输入契约、分阶段时延和真实保存重载，验收无错位/静默失败/旧结果冒充新结果。
- **思余：有条件同意。** 风险是候选表面看起来像完整物体。主责既有原图/俯视；配合罗根；交付点、来源、未知维度和失败状态；验收正常入口能核对同一位置，未观测尺寸不显示成实测。先用原图点叠加核验，不新增3D盒体视觉承诺。
- **全麦：有条件同意。** 困难是背景归属、低视差和相关误差；替代方案先人工掩码上限再自动化。主责对应/三角化/误差，配合罗根；范围既有ObjectSupport与ObservationGeometry链；交付逐点来源、离群原因、留出误差与敏感性；验收预注册正负例和覆盖率均达门。
- **小马：同意受限采用。** OpenCV/Ceres方法进入L2候选，COLMAP仅参考对照，RoomPlan有硬件条件；未证明优于现有方案，不启动迁移。主责一手来源与共用误差审查；交付本文来源及工具边界。此轮不改长期skills，方法仍待试点验证。
- **乔布斯终裁：** 采纳以上条件。跨角色统一接口为“原始像素引用+坐标版本+支持点+归属证据+误差假设+失败”，先冻结评价输入和对齐规范，再核对几何，最后联调真实入口。缺真值/素材就明确阻塞；身份、全屋闭环与全局BA不作为本轮验收替代品。
