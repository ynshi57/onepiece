# ABC 持续迭代：实际 GPU 训练与多视角深度

用户目标仍是 A/B/C 全部达标。本记录是实际实验进度，不是验收完成。

## 产品裁决与角色分工

乔布斯：不能把旧 CPU 模糊图、下载失败或指标上涨作为交付；本轮必须解决完整训练依赖，并在同一组真实留出照片看图验证。原失败产物保留。

罗根：有条件同意。使用本机 Metal，锁定源码、补丁和二进制摘要；失败不能退回 CPU 或旧结果。训练与页面共享锁、来源校验、结果状态及受限文件入口。安装脚本必须能够复现。

思余：有条件同意。空间采集页直接呈现原照片与渲染，保留所有验证照片；旋转预览明确是 Canvas 近似，不能冒充训练器渲染。新训练入口接 GPU，旧 CPU 结果继续如实标注。

全麦：有条件同意。75 张训练与13张验证完全分离，模型和渲染都要验证实际内容。PSNR 不是墙体尺寸或完整表面的证明。逐张相对深度校准仍不足，继续独立几何验证。

小马：有条件同意。Brush 官方代码存在小 JPEG 读取错误，修复准确根因，不能填充或剔除照片；DA3 Small 可做多视角几何实验，不能称为端上实时或独立米制深度。

任务接口：iPhone 原始 JPEG/K/T/epoch → 固定数据导出 → 实际训练 → 完整留出渲染 → 状态与文件 API → 用户页面。跨定位段不混合。B 的模型先验继续走独立3像素留出核对，不混入可靠测量层。

## 已取得的事实

- Brush v0.3.0，固定提交 `3edecbb2fe79d3e2c87eeab85b15e0b1dd10d486`，Rust1.88，官方依赖和 LPIPS 资源已取得。Intel Iris Plus Metal 实际执行了训练，不是 CPU 替代。
- 官方 `get_image_data` 使用 `read_exact` 读取16387字节，导致2张完整的小 JPEG报 EOF。只改成 `read`，保持损坏文件真实失败。补丁与构建回执均校验。
- 20步短训练13张全部渲染；1000步256像素训练约150.4秒、11609个高斯，完整画面平均PSNR约18.11dB。实际看图仍模糊，未验收。
- 5000步实验正在进行；不以中途评分替代最终画面。
- 官方随机初始点只覆盖相机位置的包围范围。新增可选训练照片稀疏点初始化：75训练照片得到927个点，约32.35秒，13张留出不参与。显式声明输入PLY，不依赖目录偶然文件选择。
- DA3 Small固定源码与137248940字节 safetensors摘要已校验。官方core严格载入（共享LayerNorm别名经共享存储核对恢复，未宽松忽略参数）。真实8训练视图CPU核心约1.62秒，峰值约860MB。深度图边界仍厚，固定留出几何验证尚未完成。

### 局部线与安装失败状态

新增源码OpenCV LSD C ABI（沿用现有源码构建模块，没有引入cv2 wheel）。初始75训练照片的几何线匹配有大量误配，774个局部候选尚不能直接画作房间；加入沿线真实像素外观和双向唯一性后仍继续联合拟合复核。`/line-structure`实验接口使用与高斯导出/稀疏初始化相同的`partition_epoch_frames`单一拆分，只读取训练RGB；全部候选和拒绝原因保留，原始照片及ARKit姿态不改。当前没有将未验收线直接覆盖主视图。

安装检查暴露原脚本除Brush外的profile失败会返回0。改为`add_summary`记录任意FAIL时统一返回非零，继续完成其余所选profile摘要。完整core安装/源码LSD构建/后端验证在允许本机测试HTTP端口的环境实际通过，543项测试通过；原沙箱11个端口绑定错误记录保留。额外受控FAIL验证最终exit1（此项验证安装状态逻辑，不代表模型能力）。README同步退出码约定。

### 冻结结构线核对及方向纠正

冻结66条局部结构候选后，13张未参与拟合的开发验证照片共858线–照片核对：619画外/负深、146可见无检测、59外观不符、34支持。所有失败保留，不能把66条直接称可信墙体。进一步核对三维端点发现此前按横置JPEG直觉称“墙地边界”的长线主要沿世界Y方向，实际应称竖直墙角候选；原照横置不应代替AR重力方向判断。第196/210/224/231帧该候选几何偏离分别约2.43/4.77/1.41/1.28像素，但绝对RGB侧色差大。继续训练侧照明归一与梯度描述子实验，不能直接放宽门限或删失败。结构线API分开返回训练候选和冻结独立照片核对，不用验证图修正几何。

512像素、20000高斯、5000步实际Metal实验耗时1564秒，13图平均PSNR23.11dB。实际逐张看图仍模糊，并未改善为可信房间。两组256/512实验都触及20000高斯容量，新增显式`--max-splats`资源实验参数（1000–50000），API默认仍20000；启动256像素50000预算对照。只改变可测资源预算，模型完整性检查仍校验指定预算、原误差/失败门限不变，不把增容量当通过验收。

### 实际 GPU 预览与后续反证

将Canvas近似预览替换为WebGL2实例化高斯。统一官方投影导数限幅、0.3像素协方差模糊、SH0一次转换、HDR浮点合成、黑背景及导出时实际相机内参与roll。此前网页白背景造成残余透明度被补白，SH0上限截断进一步改变合成结果。真实Chrome使用Intel Iris Plus Metal，全部13个开发验证视角与官方训练器原生渲染相比PSNR70.01–71.72dB，最大RGB通道差1–2/255；这是渲染一致性，不能作为房间重建验收。新增可复用真实像素回归脚本`spatial_splat_native_compare.cjs`，环境变量传入私人数据，源码不保存扫描ID或照片。浮点颜色能力缺失明确失败，不偷偷退回Canvas。

空间页自由视角从用户当前选择的验证照片开始。审查指出近竖直相机初始pitch被交互限幅改变，以及加载失败可能滞留旧画面；已改为初始/复位直接使用完整c2w相机basis，限幅仅用于拖动；失败隐藏旧canvas和复位入口。影响面为Brush模型JSON、网页模型选择、GPU显示与错误状态；原iPhone姿态/照片不改。

50000高斯、256像素、5000步原AR姿态实验597.99秒，13图平均PSNR24.098dB，仍有模糊/重影，部分照片回退。训练侧Ceres并推算验证姿态的同配置实验677.09秒，平均23.868dB，第168/196照片分别回退4.19/3.62dB；未替换现有模型。纠正实验记录中硬编码raw_ARKit_poses标签，明确其为训练侧校正+推算验证姿态，绝非真值。继续10000步对照，全部13图仍保留；不能以容量或步数增加宣称通过。

DA3-BASE权重下载问题已解决，固定版本SHA256验证通过。8张训练照片、280宽输入，实际CPU推理4.484秒、总7.371秒、峰值RSS1.608GB。固定1692验证候选：affine107、joint106、旧BA联合179、推算验证姿态162通过3像素；几何仍未达标，不能用模型运行成功替代准确性。DA3-BASE未加入默认生产链路。

本轮窄验证：5项Python消费者/权重产物测试、5项JS投影测试通过；真实浏览器旋转/缩放改变画面、复位像素相同，无页面错误。新增HDR测试使用实际PLY协议边界值，其本身是合成输入测试，真实13视角GPU比较另行记录。模型与结构仍未达到A/B/C验收。

补充真实反证：256像素/50000高斯/10000步耗时1374秒，13图平均24.462dB，较5000步24.098略升，但154下降2.32dB、196下降0.81dB；墙角及椅子仍重影。不能仅增加步数解决姿态、覆盖或细节问题。继续512像素/50000容量/5000步单因素资源对照，未修改默认配置。最终GPU像素回归13/13全部保留，最大通道差2/255，无脚本错误。竖直相机、加载失败清除旧模型的真实浏览器场景均通过；结构/API21项与消费者13项相关回归通过（部分集合重叠，不合计为独立34项）。

全75训练图DA3-BASE560分批推理258.9秒：37视图可校准，38视图因锚点不足或空间分布过于局部拒绝，拒绝记录全部保留。完整冻结轨迹3277候选865通过；对原8源固定1692候选只有70通过，中位10.24像素，证明增加覆盖未恢复几何能力。未以新增分母/点数宣称改善。继续按训练姿态选择有0.08–1.5米基线、70度内朝向的目标邻域帧对照，原验证RGB排除。

性能反证：真实Metal网页20000高斯900×675、12次gl.finish同步绘制，在另一GPU训练同时运行时p50 236.4ms/p95 740.6ms（含首次抖动）。不是iPhone延迟或空闲Mac验收，不能称实时；完成训练后应再测空闲与交互，两者分别保留。浏览器消费者准确度通过不意味着性能通过。

512像素/50000容量/5000步耗时1447秒，全部13验证均保留，平均23.306dB，实际墙角和椅子继续模糊重影，未采用。空闲GPU网页20000高斯900×675同步绘制12次p50 84.3ms/p95 112.3ms；与并行训练负载结果分开，不称60fps或手机实时性。目标邻域8源DA3-BASE560训练-only推理203.1秒、峰值3.149GB，固定1692候选40/59/119/159通过（affine/joint/训练BA/验证推算），继续失败，未默认启用。

经独立技术审查，将下一实验转到训练-only源码SIFT→COLMAP incremental SfM，检查AR相对位姿是否限制重建。固定每帧K，特征和主点同步+0.5转换COLMAP像素角约定，禁止用AR重投影筛匹配。留出全RGB若以后使用PnP定位相机，必须标为给定推断相机的条件评测，不能称完全未见图像独立评测；定位/评分按完整3D轨迹分离，所有注册和定位失败仍进分母。现有pycolmap临时实验依赖未接生产安装面，采用前必须同步requirements/setup/README。[COLMAP官方说明](https://colmap.github.io/legacy/3.12/pycolmap/pycolmap.html)。

源码SIFT→SfM实测：初始固定间隔368对仅注册3/75训练图。发现本机pycolmap JPEG解码返回None，而PNG可读；将同一训练RGB无损转PNG，逐图字节一致并保留失败JPEG记录，未改变几何结果。进一步完整两两2775对，注册42/75图，但形成17图/439点和25图/744点两个不连接分量，33图未注册；0.72/0.99像素训练残差不能代表全局房间或独立准确度。该结果暴露固定间隔遗漏复用视角，后续提高源码SIFT提取到1280宽/1500特征继续完整匹配，3像素核对和实际K保持不变，原失败数据不删。
