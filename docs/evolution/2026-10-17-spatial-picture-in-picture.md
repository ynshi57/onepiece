# 空间扫描双窗口（2026-10-17）

用户要求实时画面与俯视图同时显示：主窗口＋右下角小窗，点小窗交换。

- 产品：同屏观察采集内容与建图进度；停止后相机位显示已有空间预览。
- 用户追加反馈“已观察结构对我没什么用”：结构统计、观测层筛选、照片贴图证据移入底部默认折叠的“扫描详情”；主流程保留简短能力边界、错误与轨迹跳变提示。
- UI：主俯视图可拖动、缩放、双击复位；小俯视图保持全局概览；扫描引导在两种布局均保留。
- 系统审查：同一相机视图、同一 ARSession，仅改变位置与尺寸；交换不启动/停止采集。已修复组合容器覆盖子元素无障碍标识的问题。
- 影响面：SpatialScanScreen 的实时/停止/历史加载共用窗口；SpatialTopView 增加紧凑空态；历史关闭按钮增加稳定标识，避开系统语言将完成替换为 Done 的测试问题。模型、存储、协议、依赖不变。
- 模型：本轮不改识别或定位，双窗不代表空间理解准确度已验收。

验证：iPhone 签名构建通过；初版双窗口主应用安装成功，最终简化版首次安装时设备连接不可用，用户重连后安装成功且主应用启动成功；模拟器双向交换、地图拖动不滚动整页、空数据不可保存与俯视图存在检查通过；已查看两个布局的原生空态截图。历史/调试入口回归在稳定标识修改后通过；用户追加反馈后的最终两项 UI 回归全部通过（双窗交互、详情默认收起、历史/调试入口）；最终两种空态截图已人工查看。

边界：模拟器没有实景相机；真实 AR 画面交换后的投影、裁剪、叠加对齐及帧率尚未验收。本轮没有传出新手机照片，也没有运行真机照片检测批处理。照片、识别准确度与可靠三维位置仍按空间主线继续验收。
