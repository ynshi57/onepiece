# 真机画面已送达，但 Mac 滞留旧会话

用户反馈：iPhone17 点击开始共享，Mac 无画面。

## 事实与根因

读取用户真实会话：先后两次0帧启动失败，第三次成功42帧、35条事件，送达汇总为0条事件失败，进入后台停止。现场浏览器仍选中第一次0帧会话。

根因在 `device_debug.html`：仅在 sid 为空时选最新记录，之后不跟随新 session。用户重新开始共享创建新session，页面一直显示最早失败记录。前两次ReplayKit失败只有通用原因，具体原因未知，保留记录。

## 修复与影响面

仅修改 Mac 页面：默认按服务端created_at排序跟随最新会话；手动历史选择显式暂停，按钮恢复跟随。列表新增时间区分重试；零帧显示该会话停止原因。切换清旧画面、计数、时间轴和报告。图像在途去重防止轮询反复废弃慢请求；异步结果校验session/generation；图片失败单独显示，列表恢复不会掩盖。

手机/协议/凭据/服务端无修改，无需重新安装App或重启服务。所有已打开Mac调试页需要刷新载入新脚本。
