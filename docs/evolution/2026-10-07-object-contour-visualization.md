# 查看变化：直接展示轮廓证据

用户反馈：变化页只有“不能判断”，图片无变化效果，未实现物品记忆核心价值。

乔布斯裁决：本轮必须把已有掩码变成用户能看到的轮廓。参考照片橙色虚线；当前分割青色实线。背景对齐通过时叠在当前图；失败分别显示两图轮廓并允许点当前照片重新分割。不能等待身份模型校准才展示已经得到的几何信息，也不能把几何差异伪装成已确认移动、消失。

小马依据 Apple 官方前景分割、轮廓检测、图像配准文档提出方案，详见 ../tech-radar/2026-10-07-object-contour-change-overlay.md。

任务卡与接口：乔布斯负责真实用户入口与看图验收；小马研究配准方向与拒绝门；系统/模型实现负责冻结图片、掩码与特征解耦、后台配准和轮廓PNG；UI实现负责图例、照片点选与失败恢复；独立审查负责坐标、异步和结果真实性。

改动范围：IndoorTargetVision.swift（轮廓不依赖特征成功）；IndoorComparisonVisualization.swift（轮廓提取、背景配准拒绝门、渲染）；IndoorMemoryController.swift（结果状态与冻结图片点选）；IndoorMemoryScreen.swift（查看轮廓变化入口、真实图片叠层、图例）；相关测试。

影响面：仅室内物品记忆变化页与分割调用，现有extract默认保留特征要求；当前照片点选复用同一照片，不采集新帧。没有新增网络、远程模型、数据持久化或依赖；安装面无需改变。身份判定与人工确认仍分开。

验收记录将在运行后补充。真机杯子不动/遮挡/移走/相似替换场景未测之前，不标为自动事件识别完成。
