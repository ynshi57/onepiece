# 01 — 产品体验流程

受众：产品评审、非工程人员。现行规定见 [`docs/CURRENT.md`](../../CURRENT.md)。

## 一句话

VQASee 用 iPhone 摄像头持续看路。用户在屏幕上看到车道、可走区和障碍；语音只做确认。不承诺可以走或可以开。

## 面向用户的流程

```mermaid
flowchart LR
    A[移动中的人] --> B[iPhone 持续观察]
    B --> C[TwinLite 路面 + YOLO 框]
    C --> D[屏幕：车道 / 引导 / 障碍]
    D --> E[语音只确认关键变化]
    E --> F[用户自己看、自己决定]
```
