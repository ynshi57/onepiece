# VQASee 架构设计图包

这个目录用于**给人看**的架构沟通，不是底层工程调用追踪。

适用场景：产品评审、用户/投资人演示、内部规划、Figma / Keynote 重画。

建议阅读顺序：

1. `01-product-flow.md` —— VQASee 对移动中的人到底做什么。
2. `02-layered-architecture.md` —— 四层系统架构。
3. `03-model-responsibility-map.md` —— 每个模型负责看什么。
4. `04-walking-state-machine.md` —— 走路模式如何运转。
5. `05-diagnostic-learning-loop.md` —— 如何持续提升准确率。
6. `06-road-boundary-prototype.md` —— 道路边界和引导线能力如何从原型走向上线。

视觉设计原则：

> 少框、少线、清楚表达当前能力与未来能力；不制造虚假确定性。
