# 空间回放：固定方向与诊断分层

用户反馈：旋转几次后无法辨认方位与手机上下左右；实心/空心圆没有明确客户价值；不应提供需要猜测的操作。

乔布斯裁决：主流程服务照片、轨迹、相机与观测的对应。默认固定俯视，圆点/候选支持范围/匹配连线仅作为诊断，不能称物体或房间模型。计算结果失败数量继续显式呈现，不用关闭诊断层掩盖缺陷。

思余提供方案和方向推导后遇到额度限制，未执行代码；罗根/全麦独立审查也因额度未执行，不能声称本轮独立审查通过。主任务接手HTML实现、数学检查与真实浏览器看图验收。

## 实现

- 修改 `server-vqa/app/spatial_scan.html`，没有修改重建算法、schema或手机采集。
- 默认XZ俯视。选中照片所属epoch的首个有效水平forward作为起始参考；screen-right=(-fz,fx)，screen-up=(fx,fz)。仅同epoch轨迹/面/点直接展示，其他定位段不直接拼接，显示当前段提示。不是地理北。
- 三维pitch限制0.15..1.35保持Y向上；提供回到俯视和对准镜头朝向。对准yaw=atan2(-fx,-fz)，使镜头水平朝向的屏幕横向分量为0。镜头近竖直时禁用水平对准。
- 手机右/上从保存displayTransform的2×2线性部分求逆，映射显示右(1,0)、上(0,-1)到原始图像，按width/fx、height/fy转换AR相机向量，再乘cameraToWorld旋转。镜头前=-T第三列。未知显示方向或奇异变换不猜测手机轴，旧记录明确提示。
- 手机方向在固定位置以颜色、文字和当前视图投影箭头表示，避免在相机位置重叠。与世界轴和地理方位明确区分。
- 点、支持范围、照片投影、失败细点默认关闭且诊断折叠；没有对应结果时控件禁用并说明。失败分母、完整误差与原始证据仍保留可见/可下载。关闭诊断不改变数据或计算结果。

## 验证

主任务使用真实104张扫描浏览器操作：默认axis=xz，点/轮廓均关闭，未重建点控件禁用，诊断折叠；生成结果后启用诊断控件且默认仍关闭；949留出尝试391通过558失败以及全误差p95 16.15仍在主页面；三维拖动pitch限位不倒置，回到俯视成功；已计算结果的点层可打开；切换198张旧记录明确无法核对手机方向；浏览器脚本错误0。

初次看图方向文字在相机附近重叠，修为固定位置再看图。镜头对准的yaw符号经几何检查修正，不用按钮存在代替方向正确。JavaScript语法检查与git diff --check通过。无iOS改动，未运行iOS测试；没有新增依赖或修改安装流程。

影响面仅Mac页面展示、默认图层和控件可用性；同页照片/时间轴/匹配/证据下载消费入口同步。剩余能力风险：几何、墙地语义和尺度尚未恢复；本轮改善查看方式，不代表准确度改善。独立跨角色审查未完成是明确限制。
