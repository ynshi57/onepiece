# VQASee 中文 Skill 草案

这些文件是给你审核和修改的 **中文草案**，暂时不作为正式 Codex skill 安装。

建议先调整这些草案，再决定是否复制/安装到：

```text
~/.codex/skills/
```

第一批建议做 5 个 skill：

1. `vqasee-self-evolution`：VQASee 自闭环、自我进化总控 skill。
2. `vqasee-product-review`：乔布斯产品审查 skill。
3. `vqasee-performance-audit`：罗根系统性能审查 skill。
4. `vqasee-ui-polish`：思余 UI/可访问性审查 skill。
5. `vqasee-model-prompt-lab`：全麦模型/prompt/后端审查 skill。

其中最关键的是 `vqasee-self-evolution`，它负责把用户反馈、测试结果、代码问题、产品目标转成下一轮改进任务，并沉淀到规则、测试、文档和路线图里。
