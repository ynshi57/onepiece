# docs 怎么读

先读两页，再按需打开一篇日期日志。不要通读本目录。

| 读这个 | 它是什么 |
|---|---|
| `CURRENT.md` | 今天产品是什么、目标缺哪几条、验证后仍在的缺陷 |
| `SPATIAL_HANDOFF.md` | 室内建图只读这一页 |
| `roadmap.md` | 以后再做的队列。和 CURRENT 冲突时以 CURRENT 为准 |
| `decisions/` | 历史裁决。8 月里的「语音优先」等句子已作废 |
| `architecture/design-pack/` | 给评审看的分层图。实现以代码和 CURRENT 为准 |

`evolution/`、`model-lab/`、`tech-radar/`、`performance/`、`ui-lab/` 共一百多篇，是各轮实验的证据。里面有过时方案，也有看图失败的记录。失败结论已经收进上面两页，原文留着是为了还能核对，不是为了再执行一遍。

不要把这些日志整段载入上下文。要某个数字时，只打开状态卡或 CURRENT 指向的那一篇。

新结果写进带日期的新文件。不要把分贝列表抄回 `CURRENT.md`。同一假设第二次看图失败就停，写进日期日志，不换一个旋钮再开一臂。
