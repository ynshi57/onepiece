目标是补足低纹理墙面的重建证据，不把学习模型的输出伪装成测量真值。A/B/C均未因此验收。

## 真实扫描实验

Intel Mac、CPU、4线程、batch1，官方Small/DINOv2 encoder+DPT decoder。518输入，保持宽高比与14倍数对齐，实际张量为 `[1,3,518,686]`。相对深度输出恢复原始照片尺寸。

预先仅按训练特征覆盖选择同一坐标epoch的3帧。原候选因训练anchors不足被记录，未读取评测照片或模型结果来挑选成功样本。

|---|---:|---:|---:|---:|
| 174 | 1.593s | 755MB | 121 | 6.20% |
| 188 | 1.489s | 788MB | 133 | 7.89% |
| 220 | 1.454s | 788MB | 149 | 1.28% |

首次加载41.882秒另计。以上均是Mac离线数据，不是iPhone端延迟。对照看原图和彩色深度，白墙和家具层次可见，但边界简化、细节缺失。

### 第二轮：跨照片几何门失败

8个训练视图推理和校准完成，产生2400个model_prior seed。独立13个heldout视图保留1692个候选：82个达到固定3像素重投影门槛（4.85%），1610失败；其中928个没有已选训练prior对应，681个投影误差失败、1个出画。764个已投影候选的误差中位数8.79像素、p95为37.15像素。3个heldout视图没有featureTracks支持，明确保留为失败。

模型自身z-buffer检查中58个一致、11个被其它prior遮挡，剩余未支持或不可用；同时达到重投影和自遮挡检查仅6/1692。该检查不是遮挡真值。结论：不能作为可靠表面输出，单图视觉合理与训练拟合小残差都不能替代跨视图几何。

下一轮已执行拆解：训练深度尺度联合优化与训练姿态约束分别对照，保持独立heldout与固定阈值。先判断深度、姿态、误匹配各自贡献，再选择是否进入GS初始化实验。

完整高斯训练器另行采用 [Brush 官方项目](https://github.com/ArthurBrussee/brush) 研究与本机编译；本文件不宣称它已构建成功或画质已达标。

### 更强模型与结构约束的候选

[DA3-BASE 官方模型卡](https://huggingface.co/depth-anything/DA3-BASE)标明 Apache-2.0、支持多视图/已知姿态；固定权重提交 [`6544606276a24280a81c2e8d6af456870ff34f4e`](https://huggingface.co/depth-anything/DA3-BASE/commit/6544606276a24280a81c2e8d6af456870ff34f4e)，[官方 LFS 指针](https://huggingface.co/depth-anything/DA3-BASE/blame/main/model.safetensors)给出 541,518,028 字节与 SHA256 `e01067dc1659613083d9145a9a2547ccdbe6ccbbf83c4fe7b3e8a4e2bdae78b5`，符合 <700 MB 的可控离线实验上限。已尝试固定 revision 的官方地址和镜像进行 range 请求；此前本机代理 CONNECT 超时，复试时代理端口拒绝连接、直连DNS无法解析。截至本记录尚无已验证权重，故没有推理或性能结论。不可从 README 的参数数估算实际权重大小或从未完成下载包装成功。

低纹理墙体可以测试线段与 Manhattan 平面约束，而不是继续调单图深度门槛。[PL-VINS 官方实现](https://github.com/cnqiangfu/PL-VINS)证明点线视觉惯性路线可研究，但仓库为 GPLv3、Ubuntu/ROS 实现，不能直接作为本产品的可商用集成包。[Structure PLP-SLAM 官方实现](https://github.com/PeterFWS/Structure-PLP-SLAM)整合点、线、面，但亦为 GPL-3.0，且平面分支依赖外部分割结果；不能将其现成源码并入当前 App。[OpenCV 官方项目](https://github.com/opencv/opencv)为 Apache-2.0，可用其 LSD 检测作为本机训练图证据探针，后续自己实现受约束几何。无可靠跨视图线匹配时，单张白墙边界只能给方向，不能给墙距或房间尺寸。最小实验必须先量化同一批训练照片里的长线段、重力/Manhattan方向支持和跨视图同一物理线的匹配可用性，再只用训练证据拟合平面，继续用同 13 张留出及固定1692点门核验；缺少匹配或尺度支持则明确失败。

本机第一步已执行 `/tmp/vqasee-line-manhattan-experiment.py`：同8张训练照片缩至640像素宽，OpenCV LSD 共检出2997段，其中154段长度至少60像素、51段与 ARKit 重力在图像中的投影方向相差不超过5°，1.04秒 CPU。逐帧真实照片与线段叠加保存在 `/tmp/vqasee-line-manhattan-v1/`。看图发现第188帧可见墙/地板长边；第220帧白墙大面积仍缺纹理，长线主要来自笔记本和显示器。此处**没有**验证任何跨视图同物理线匹配，匹配数记0，墙距/尺寸仍不可得，也没有进入1692点几何分母的改善成绩。下一实验的入口条件是先由训练帧检验线段匹配可重复性，而非仅看检测总数。

训练-only 的第二步 `/tmp/vqasee-line-match-probe.py` 用既有SIFT轨迹在640像素宽图上关联距长线段4像素内的点，得到9对候选线段；仅1对有至少3个共同训练轨迹（187↔188帧，5条轨迹）。原照片叠加 `/tmp/vqasee-line-match-probe-v1/frame-188-pair6.png` 显示这对属于家具/暗色物边缘，并非白墙边界。它尚未通过同物理线三角化验证，不能支撑墙面尺度或改善1692点成绩；这条依赖点特征的途径未找到白墙跨视图约束。此探针只使用训练图，没有读取评测RGB。

第三步另做**不依赖SIFT**的训练-only线几何验证 `/tmp/vqasee-line-only-geometry.py`、`/tmp/vqasee-line-third-view.py`。第187、188帧中肉眼对应的白墙/地面边界为LSD长线2↔4；两条成像射线平面交会角4.06°，估计可共同观测的线段0.835米。所有长线两两配对经正深度、有限长度与投影段重叠约束后仍有15个候选（Ceres训练位姿14个），该墙地边界排第一，但单靠几何并非唯一匹配。用**原始ARKit训练位姿**将这条候选三维线投到其余全部73张训练照片：28张按正深度及视野判断可见，19张在固定方向差≤5°、正交距离≤8像素、重叠≥40像素下找到LSD长线，9张没有匹配，均保留。第186、190、192帧原照片叠加 `/tmp/vqasee-line-third-view-v1/frame-186-third-line.png` 等显示洋红预测线与绿色检测线落在同一墙地边界；第170和230帧亦可核对。这个独立于源双视图的**训练照片**复现比仅数长线更强，但可见判定未处理遮挡、三角化交会角小、未用13张冻结留出RGB，也没有独立墙面米制真值。因此只升级为局部结构候选，不能宣称完整墙体或房间尺寸已恢复，1692点几何门没有因此改变。

此探针已落成 `server-vqa/app/spatial_line_structure.py` 和既有源码构建库的 `spatial_lsd` C ABI；不把临时实验的 Python `cv2` wheel 变成 core 隐性依赖。真实75张训练照片、同一原始位姿、OpenCV固定源码4.11.0的运行耗时20.8秒，85个相机对通过视野门、23066个源线对进入检验，774个有至少1张第三训练图的局部线**候选**；大量候选会是假阳性，不能把774条全部显示成可信墙体。固定墙地边界在源码版的线索引变成187:2↔188:3，估计0.80米局部段；73张第三训练图中20张线支持、9张几何可见但无检测、44张不在视野或负深。全部候选和失败理由留在 `/tmp/vqasee-line-structure-module-75.json`，原先 wheel 版19/28数字亦保留，算法版本差异不伪装为同一结果。`localLines[*].endpointsWorld` 仅是候选双端点，不含墙面语义或物理精度验收。

继续用**同一23066源线对**修正纯几何误配：按三维候选线在训练照片的真实像素位置取线两侧RGB，中位颜色差≤0.08且两侧对比≥0.10；源照片双向唯一线匹配；第三训练图同样检验外观；多视图共同拟合三维线，逐视图端点重投影残差中位≤3像素、p90≤6像素；最后对相距≤5厘米且方向/长度重合的候选做显式去重，所有淘汰线仍保留原因和重复指向。修正后的同75训练图：117条有第三视图与联合拟合支持，51条标为重复，66条保留为不同的**局部线候选**，18.9秒；完整证据在 `/tmp/vqasee-line-structure-final-75.json`。目标墙地线仍在，7张第三训练图经过外观核对，联合重投影残差中位0.56像素、p90 1.21像素。原照片叠加 `/tmp/vqasee-line-structure-final-frame188.png` 中绿色目标边界位置合理，红色其他候选含家具线及可疑线；66条仍不能直接作为用户主视图墙体。

训练结果冻结后，再由分离的 `validate_line_structure(...)` 只读13张留出RGB，逐条核对66×13=858个线-照片组合：619个不在视野或非正深度，146个可见但无LSD线匹配，59个几何近似但线邻域外观不符，34个几何与外观均支持；所有失败留在 `/tmp/vqasee-line-structure-frozen-13.json`。目标墙地线仅在第189张留出照片得到支持；其余12张中6张不可见、2张无检测、4张外观不符。13张原照片逐张叠加在 `/tmp/vqasee-line-structure-frozen-13-overlays/`，第189帧青色目标线对齐边界，第196、210、224、231帧洋红预测线与失败状态也可见。该核对没有重训、挑选或删除候选；34/858并非墙面准确率，因为大量组合本来不在视野，34/239可见组合亦不足以证明稳定墙体。结论仍为B未过门。

乔布斯：维持 B 未过门，不以更漂亮三栏图替代真实空间可信度。罗根：CPU和内存仍是离线预算，线/平面优化只能建在现有 ARKit 位姿与可观测失败路径上。思余：模型深度保持“估计”标注，画面必须保留失败红点。全麦：DA3-SMALL 实测劣于 DA2，BASE 只作为下一次受控实验，不预设提升。小马采纳分级：Small L1 反证沉淀；BASE L2 待权重校验；点线平面 L2 待真实跨视图匹配。下一次优先搜索可商用许可的线段匹配与 iPhone 离线几何优化实现，不更新长期 AGENTS 规则。
