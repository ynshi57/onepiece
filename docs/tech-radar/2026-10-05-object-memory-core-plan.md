# 物品记忆核心能力：技术调研与实验计划

状态：一手资料核查完成；候选均未完成VQASee实测，非模型选型或发布承诺。此次只改研究文档，不改运行代码。

## 产品目标与顺序

用户确认：再次观察时主动发现仍在、原处未见、移动到新处；遮挡/未观察/定位失效是无法确认。人工确认只作纠错和真值采集，不能替代自动能力。先同一房间同一会话，再跨启动；先刚性日用品，再透明、反光、柔软、相似外观难例，不把这些难例从失败统计中删除。

1. 首先建立本地录制/回放：图像、相机内参/位姿、时间、方向、可选深度与跟踪状态，明确开启与删除，默认不上传。普通录像可评估外观，不能单独验证空间对齐。
2. 记录物品的多视角局部外观、轮廓、周围背景和位置不确定性。引导小幅移动拍2–3个视角，不先要求完整重建房间。
3. 先闭环原处变化：恢复原区域→判断是否确实可见→对齐背景/几何→比较物品与腾空后的背景→连续多帧证据→仍在/原处未见/无法确认。外观距离和“没分割到”单独都不能证明消失。
4. 再闭环新位置：原处未见后，在当前看到的场景产生候选，用多视角外观、形状与几何匹配排除相似品；证据不足保留候选而不是强认。只对观察到的区域负责。
5. 再跨启动：地图恢复与物品身份分别验收；空间位置失效不能让语义身份/旧照片静默消失。

## 一手技术情报与采纳等级

| 路线 | 来源与事实 | 用途与风险 | 等级 |
|---|---|---|---|
| Apple ARKit/Vision | [sceneDepth](https://developer.apple.com/documentation/arkit/arconfiguration/framesemantics-swift.struct/scenedepth)：LiDAR设备提供同步深度；[对象扫描](https://developer.apple.com/documentation/arkit/scanning-and-detecting-3d-objects)：参考对象空间特征，刚体更合适 | 当前端侧基线；深度用于对齐/遮挡证据，不能证明身份；原型不具备全部可见性判断 | L2/VQASee基线待测 |
| SAM 2 | [官方项目](https://ai.meta.com/research/sam2/)、[官方代码](https://github.com/facebookresearch/sam2)：图像/视频提示分割，视频中传播mask | 离线比较轮廓和连续跟踪；不等于跨时段身份、不等于消失检测，未证实iPhone实时 | L2离线候选 |
| DINOv3 | [官方实现](https://github.com/facebookresearch/dinov3)：高分辨率稠密视觉特征，多个模型大小 | 与现有Vision feature print对照跨视角匹配；相似物品误认与iPhone耗时未知，权重获取/许可需核实 | L2离线候选 |

## 最小实验与准入

探索样本：5件实物 × 6种事件 × 2次独立拍摄 = 60段短序列，仅用于发现问题，不足以证明泛化。事件：未动、移走、移动到可见新位置、遮挡、换成相似品、只改变视角/光照。加入离开再回来、后台再开与新房间作为后续独立测试集。调参集和测试集按实物/拍摄会话分开，不拆相邻帧假装独立样本。

对照：现有Vision基线 vs SAM 2轮廓/视频传播 vs DINOv3匹配；模块分别替换，保持同一输入和真值。先跑离线准确度，再测候选端上资源，不立即训练大模型或购置硬件。

指标：错误“原处未见”次数/未移走事件、真实移走召回、相似品误认、自动结论覆盖率（防止全部回答不确定）、轮廓IoU、定位误差、恢复成功率、判断p95及功耗/温升。无法记录、无法分割、定位失败、超时均保留并计入；速度起点是原区域重新可见且完成所需观察，不是函数开始。

探索阶段希望典型日用品变化检出≥90%、未动/遮挡/换角度误报≤5%，自动判断覆盖≥80%、重新看清后2秒内给结果。这些是待样本与设备约束审查的候选目标，60段不能证明低误报率；独立扩大测试再裁定发布门槛。若高误认，优先增加多视角/背景证据；不能通过只报不确定达到表面准确。

## 用户支持与边界

优先需要iPhone型号/iOS版本；一组可重复摆放的日用品（含两个外观接近的物品）；约20–30分钟首轮采集。先在家进行，避免旁人入镜。采集工具、清单与标注模板由开发方提供，用户只需按步骤摆放和扫视，样本默认留本地。现有Mac算力先核查，不要求用户先买GPU；若候选确需远程算力，再给出具体预算、数据范围与审批。
