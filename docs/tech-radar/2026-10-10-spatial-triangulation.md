# 原始相机证据驱动的稀疏空间重建

2026-10-10 · 小马技术支持，全麦几何实现，罗根审查分母与独立性，思余消费可见证据，乔布斯裁定不冒充房间语义结构。

## 方法与一手依据

[OpenCV 4.11 相机模型与三角化文档](https://docs.opencv.org/4.11.0/d9/d0c/group__calib3d.html)定义像素齐次投影 `p ~ K[R|t]X`。[官方 triangulate.cpp](https://github.com/opencv/opencv/blob/4.11.0/modules/calib3d/src/triangulate.cpp)用 `uP3-P1` 与 `vP3-P2` 的线性约束组成矩阵，经 SVD 求齐次点；引用 Hartley/Zisserman 多视图几何。当前 NumPy 实现采用相同 DLT 数学，随后明确检查有限齐次解、正深度、视差与逐帧重投影；这不是修改或重新编写 SIFT。[COLMAP FAQ](https://colmap.github.io/faq.html)把两视图轨迹和小三角化角作为应慎重处理的重建因素。本实现仍展示两视图点，但明确没有第三视图核对，禁止把它们当独立证明。

特征提取调用仓库现有的 OpenCV 4.11 原源码 SIFT 桥接库，其完整 core/imgproc/features2d/flann 支持依赖仍存在，没有增加 Python 包或声称零依赖。缺失库明确返回不可用。描述子用双向 ratio 匹配，独立 NumPy F/H RANSAC 建立图像对应，不依赖 AR 位姿。

每张照片使用自己的原始 K 和 cameraToWorld；104 张照片的焦距存在约 29px 波动，不能用固定 K。AR 相机看向 -Z、Y 向上，转换到像素相机 +Z 前方、Y 向下；JPEG、K 和 T 均不随显示方向旋转。缩小图提取的关键点由既有提取器以像素中心约定返回原始照片像素。时间、epoch、矩阵和 pose 一致性均检查。不同 epoch 不连接。镜头畸变、滚动快门、绝对尺度和 AR 漂移没有真值验证，`scaleVerified=false`、`poseOptimized=false`。

## 必须避免的验证泄漏

早期 v2/v3 原型先通过 AR 两帧误差门槛再建立轨迹，随后保留最后一帧核对；这个轨迹已被该帧位姿选样，因此不能称独立留出。保留原型工件用于审计，不能作为最终验收。

v4 轨迹只由图像 F/H 内点、特征身份无冲突和 epoch 构成。固定留出轨迹中的最后一帧，所有其余观测训练 DLT；留出帧的 K/T 和像素不参与拟合、baseline 选择或训练误差门槛。配对 AR 三角化仍作为诊断保留，不能筛选轨迹。训练 baseline >=3cm、最大射线视差 >=1°、每训练帧误差 <=3px，留出核对 <=3px。失败候选与全部有限残差保留，成功集分位数另标 `passedOnly`。`holdoutDiagnostics` 保存每次尝试的原图观测像素、预测像素、误差、通过/失败状态与训练帧；负深度无法投影时明确 null，失败投影供 UI 红色证据查看，不加入接受点。对应回归测试故意给留出照片增加 20px 图像偏移，仍须产生 36 次尝试和 36 次失败，不能因 AR 两帧失败把它们提前丢掉。

## 真实 104 张验收

唯一样本 `F4E09FA6-EDAD-46FA-928D-92DAA4ADFBEF`，104 个关键帧、585 个 pose，epoch=2；原始文件未改变。最终真实工件 `/tmp/vqasee-reconstruction-104-blind-holdout-v4.json`，之前 198 张房间样本未混入。

- 全部 104 张实际调用原源码 SIFT，邻接偏移 1/3/6，302 对全部保留，187 对产生可提交点。
- 1101 点：391 点通过留出核对，710 点仅两视图支持。
- 5692 条有留出候选轨迹；4743 条训练几何失败；949 次真正留出尝试，391 次通过、558 次失败，通过率 41.20%。不能用 391/1101 当通过率。
- 全部 949 个有限留出误差 median=3.504812px、p95=16.149953px。仅通过者 median=1.701369px、p95=2.852980px；必须同时展示失败分母。
- 9033 条轨迹拒绝：训练 baseline 4224、小视差 2648、训练高误差 1578、留出失败 558、负深度 25。
- 提交点 3391 次观测误差 median=1.192507px、p95=2.708481px。它们是条件通过集，不等于所有匹配准确度。
- 最终完整运行（含原图颜色与 949 条核对诊断）耗时 72.707 秒：SIFT 11.901 秒、配对 55.294 秒、多视图与颜色 5.418 秒、候选面 0.093 秒。此离线计算不声称 iPhone 实时。

点颜色直接采样首训练观测原 JPEG 的 3×3 RGB 均值，记录 source frame/pixel，按帧读入后释放；不生成颜色、不改变几何。图像读取失败显式 `colorSamplingError`。点数上限 20000、配对上限 320、frame 上限 240，触发容量限制明确返回，不能静默丢数据。

## 点支持的矢量轮廓

只用留出核对通过的点，按 epoch 做确定性 RANSAC 平面与 PCA 细化。支持至少 30 个不同 2cm 空间单元，点面距离 <=3cm，主跨度 >=30cm、次跨度 >=15cm；最多 8 个候选，容量限制与失败原因有记录。当前真实样本形成 3 个候选面。

输出凸支持包络、多边形顶点、normal/offset、支持 point IDs、残差、跨度、面积和照片证据。凸包会填补缺失观测之间的空隙，它是已观察点的几何包络，不是完整墙轮廓。原 AR observed surfaces 只做同 epoch 角度、距离、观测多边形内比例关联，不修改原面。倾斜方向不能提供墙/地板语义：所有候选 `semanticLabel=null`、`semanticVerified=false`、`completeBoundary=false`。真实墙/地板模型与真值未提供，不能伪造语义结论。

## 审查与交付边界

罗根要求的防位姿选样泄漏与完整分母已落实；全麦要求的逐帧 K/T、负深度、视差、重投影与真实样本验证已落实。思余通过 API 在原图展示真实像素证据、3D 颜色点与支持包络，禁止面填充冒充房间。最终用户画面与 API/browser 联调由主任务验收，单元测试不能代替看图。14 项窄测试通过，其中解析几何与 injected descriptor 测试明确只是控制实验，以上真实 104 张结果才是实际 SIFT 测量。

目前不能宣称完整房间、绝对尺寸校准、墙地语义或即时重建。真实留出失败率很高，必须在页面明确展示，并作为后续位姿漂移、匹配歧义与采集质量分析依据，不可通过改门槛或仅统计通过者掩盖。
