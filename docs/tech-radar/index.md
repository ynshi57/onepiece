# VQASee 技术雷达

小马维护这个目录，用于沉淀外部新技术、新模型、新工程实践、AI Agent / Agent 工程认知，以及这些认知对乔布斯、罗根、思余、全麦的影响。

## 使用规则

- 单项技术情报使用 `_template.md` 创建：`YYYY-MM-DD-主题.md`。
- 不只保存链接，必须包含可信度、成熟度、VQASee 机会、风险、分角色学习卡和最小实验。
- 如果认知改变长期工作方式，同步更新 AGENTS.md 或对应 skill。
- 如果认知影响模型路线，同步 `docs/model-lab/`。
- 如果认知影响性能/架构，同步 `docs/performance/`。
- 如果认知影响长期产品或架构路线，同步 `docs/decisions/` 或 `docs/roadmap.md`。

## 技术采纳分级

| 等级 | 含义 | 动作 |
| --- | --- | --- |
| L0 | 记录观察 | 暂不行动，保留线索 |
| L1 | 学习更新 | 更新 docs / skill / AGENTS，不写代码 |
| L2 | 最小实验 | 设计小样例、benchmark、prompt 或脚本验证 |
| L3 | 产品候选 | 实验有效，进入 roadmap 或 decisions |
| L4 | 生产落地 | 有测试、监控、回滚、发布验收 |
